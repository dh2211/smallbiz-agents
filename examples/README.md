# Examples

Each file is a worked output from following the skills for one invented business. The owner request at the top of each file is what the agent was given. Every business, customer, price, and review here is invented. Prices are in a generic currency.

These outputs were written by following the skills by hand, not recorded from a live run in an AI tool.

| Example | Skills used |
| --- | --- |
| [Candle shop: new product and spring promotion](candle-shop-spring-promotion.md) | `biz-product-description`, `biz-promotion-plan`, `biz-social-post` |
| [Café: review replies and a closing checklist](cafe-reviews-and-closing.md) | `biz-review-reply`, `biz-sop-writer`, `biz-checklist-builder` |
| [Painter and decorator: quote to invoice](painter-quote-to-invoice.md) | `biz-quote-builder`, `biz-invoice-builder` |

Use them to see what good output looks like, and as test cases when you change a skill: follow the changed skill with the same request and compare.
